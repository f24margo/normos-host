# Чек-лист стабильности NormOS (Smoke Test)

Этот документ используется перед каждым релизом и демонстрацией для предотвращения регрессий.

---

### 1. Слой нормативных карточек (MSU UA)
- [ ] Все 51 карточка в `packages/msu_ua/cards/` валидны (содержат `id`, `title`, `verbs`, `default_modality`).
- [ ] Карточки корректно проиндексированы в `packages/msu_ua/index/by_verb.json`.
- [ ] Отсутствуют необработанные карточки без привязанных глаголов.

### 2. Экстракция, Роли и OOV (`roles.py` / `triplets`)
- [ ] Главный субъект извлекается в именительном падеже (прямая связь).
- [ ] Контекстные субъекты помечаются флагом `is_contextual: True` (мягкая связь).
- [ ] OOV-детектор отрабатывает по корневой политике (для слов >=6 символов).

### 3. Визуализатор Графа (`graph.py` & UI)
- [ ] Функция `build_dependency_graph` (и алиас `build_norm_graph`) работает без `KNOWN_HUBS`.
- [ ] В консоли браузера при рендере Vis.js отсутствуют JS-ошибки.
- [ ] Чекбокс **«Контекстні суб'єкти»** переключает видимость пунктирных связей.

### 4. Интерфейс Инспектора (`workspace.html`)
- [ ] Синие карточки норм отображаются под соответствующими триплетами.
- [ ] Складки/панели инспектора переключаются без сбоев верстки.
