NormOS Host
Платформа виконання NormOS — захищене робоче місце в браузері для розбору текстів актів місцевого самоврядування.
NormOS Host побудований на Django 6 і Python 3. Він дає посадовим особам громади (секретар, юрист та ін.) можливість увійти в кабінет, передати текст проєкту рішення, регламенту чи протоколу й отримати структурований розбір: типові нормативні дії, орієнтовний режим формулювань, службові підказки для подальшої людської перевірки.
Лінгвістичний аналіз спирається на ядро NormOS (реєстр нормативних дієслів, правила контексту). За потреби підключається довідковий ШІ-помічник — не як джерело юридичного висновку.
Host не є органом влади, реєстром актів чи юридичною консультацією. Система не засвідчує законність документа й не замінює рішення ради, юридичного відділу або відповідальної посадової особи.

## 🔑 Ключовий функціонал

* **⚡ Швидка перевірка (Fast-Check Workspace):**
  * Автоматичний аналіз завантажених документів (PDF, DOCX, TXT) на дотримання вимог нормопроектувальної техніки.
  * Виявлення нормативних дієслів та маркерів юридичного контексту за допомогою спеціалізованих лінгвістичних баз (`norm_verbs_uk.json`, `context_markers_uk.json`).
  * Ідентифікація позасловникової лексики (OOV) та специфічної термінології.

* **🤖 ШІ-Консультант (NormOS AI Assistant):**
  * Інтерактивний чат для глибокого аналізу правових норм та консультування посадових осіб місцевого самоврядування.
  * Контекстний підказчик та перевірка узгодженості актів із чинним законодавством України.

* **📁 Реєстр та Архів Документів:**
  * Централізований контроль версій завантажених проектів рішень та нормативних баз.
  * Безпечна завантаження та скачування аналітичних звітів і оброблених файлів.

* **🛡️ Безпека та Розмежування Доступів:**
  * Повноцінна система автентифікації користувачів (Login / Logout / Session management).
  * Захист від CSRF, налаштовані заголовки безпеки та розмежування прав доступу.

## 📐 Архітектура та Технологічний Стек

Платформа побудована на сучасному та надійному стеку технологій:

* **Backend:** Python 3.13.5, Django 6.0.7
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla UI з адаптивним дизайном та сайдбаром)
* **AI & NLP Processing:** LLM Engine (Gemini API Integration), Custom Rule-Based NLP Analyzers (`analysis.py`, `services.py`)
* **База даних:** SQLite3 (з можливістю масштабування до PostgreSQL)
* **Експорт та інструменти:** Скрипти аналізу та експорту (`export_triz.py`)

### Структура проекту

```
normos-host/
├── data/                       # Лінгвістичні класифікатори та словники
│   ├── context_markers_uk.json # Маркери юридичного контексту (укр.)
│   ├── norm_verbs_uk.json     # Словник нормативних дієслів та модальностей
│   └── oov_log.jsonl           # Логування позасловникової лексики
├── host/                       # Основні налаштування Django-проекту
│   ├── settings.py             # Конфігурація середовища, сесій та безпеки
│   └── urls.py                 # Головні маршрути платформи (Workspace, Chat, Docs, Auth)
├── hostui/                     # Основний додаток користувацького інтерфейсу
│   ├── analysis.py             # Модулі лінгвістичного та аналітичного аналізу
│   ├── services.py             # Сервіси взаємодії з ШІ та обробки документів
│   ├── views.py                # Контролери сторінок (workspace, chat, documents)
│   └── templates/              # HTML-шаблони (workspace, chat, documents, login)
├── scripts/                    # Допоміжні скрипти та аналітичні утиліти
├── manage.py
└── db.sqlite3
```

## 🚀 Встановлення та Запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/f24margo/normos-host.git
cd normos-host
```

### 2. Налаштування віртуального середовища

```bash
python3.13 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Змінні середовища

Створіть файл `.env` у кореневій директорії або експортуйте ключ Gemini API:

```bash
export GEMINI_API_KEY="your-api-key-here"
```

### 4. Запуск міграцій та сервера розробки

```bash
python manage.py migrate
python manage.py runserver 127.0.0.1:8000
```

Після запуску платформа доступна за адресою: `http://127.0.0.1:8000/workspace/`
